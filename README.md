# AI Response Evaluation — Fact-Checking & Bias Analysis

## 1. Project Overview

This project evaluates AI-generated responses to investigate factual accuracy, consistency, uncertainty handling, and potential bias.

The goal is to identify and document observable issues using reproducible tests and reliable evidence.

## 2. Objectives

- Evaluate factual accuracy.
- Compare responses to equivalent prompts.
- Test consistency across repeated attempts.
- Investigate potential bias using explicit criteria.
- Document evidence and limitations.
- Suggest improvements based on observed results.

## 3. Testing Methodology

1. Define the test objective.
2. Record the exact prompt.
3. Save the model response.
4. Verify factual claims using reliable sources.
5. Repeat the test or compare equivalent prompts.
6. Document expected and observed behavior.
7. Assess severity based on evidence and potential impact.

## 4. Evidence and Limitations

A difference between AI models is not automatically a failure.

Findings must distinguish verified errors from uncertainty, interpretation differences, and subjective judgments.

Potential bias must be assessed using explicit criteria and supporting evidence.
